# 文案风格分析报告

## 一、整体印象锚点
- **阅读后的主要情绪感受**：（例如：轻松、紧张、温暖、严肃、好奇、被冒犯等）
- **人格化想象**：如果文案是一个人，他/她的年龄、身份、性格是怎样的？
- **场景与媒介联想**：这段文字更像出现在哪里？（如：朋友私聊、学术论文、短视频脚本、品牌官网、深夜电台等）

## 二、微观语言特征拆解

### 1. 词汇层
- **用词偏好**：（口语/书面语、专业术语/大白话、古语词/网络热词，并举例）
- **词性特点**：（多用动词/名词/形容词，动态感或渲染力如何）
- **程度与态度**：（是否频繁使用绝对词如“绝对/必须”，或模糊词如“也许/有点”，或情绪词如“竟然/遗憾”）

### 2. 句法层
- **句子长度与节奏**：（短句为主/长句为主/长短交错，举例说明）
- **句式结构**：（陈述句/疑问句/感叹句/祈使句的分布，是否频繁使用设问、反问）
- **典型句式举例**：（摘录1-2个代表性句子）

### 3. 修辞层
- **常用修辞手法**：（比喻、拟人、排比、夸张、反复、反讽、用典等，并各举一例）
- **韵律与声音**：（是否押韵、有重复词句、或刻意制造节奏感）

### 4. 格式与视觉层（若文案为屏幕文字）
- **段落与换行**：（密集段落 vs 频繁换行）
- **排版符号**：（emoji、特殊符号如→ ~ *、全角标点等使用情况）
- **大小写与空格**：（英文全大写？中文内是否留空格？）

## 三、宏观内容与视角

- **叙事视角**：（第几人称；“我/你/他/我们”的使用效果）
- **信息密度与逻辑**：（信息密集、逻辑环环相扣，还是观点稀疏、氛围先行；主要靠数据/道理/故事/共情来推进）
- **情感基调与核心价值观**：（表面情绪是什么？背后有无一以贯之的态度或价值观？）

## 四、对比参照（可选，若有明显参照物可写）
- **与同类主题常见风格的差异**：（例如：“与常规科技评测的冷静客观不同，本文带有强烈的个人吐槽色彩”）
- **独特风格标签**：（如“冷嘲式知识分子幽默”、“拟人化官方亲切”、“碎片化社交媒体体”）

## 五、综合风格画像
用一段话（或关键词云）总结该文案的整体风格特征。要求能让没读过原文的人大致想象出其调性。

示例格式：
> 该文案呈现典型的「________」风格：
> - 词汇上：________
> - 句法上：________
> - 内容上：________
> - 情感上：________
> - 独特之处：________

## 六、 目标仿写
模仿输入文案的整体风格特征，对目标文案进行仿写，使其具备与输入文案的风格特征

输出格式：
> 仿写： [仿写内容]
