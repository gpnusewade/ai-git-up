# Design Principles Reference

## Visual Hierarchy
1. Size - Larger elements attract attention first
2. Color - Bright/saturated colors stand out
3. Contrast - High contrast draws focus
4. Proximity - Related items grouped together
5. Whitespace - Breathing room around important elements

## Typography Scale (Modular Scale)
Use ratio 1.25 (minor third) or 1.333 (major third)

| Element | Size (rem) | Weight |
|---------|------------|--------|
| H1 | 2.5-3.5 | 700 |
| H2 | 1.8-2.2 | 600 |
| H3 | 1.4-1.6 | 600 |
| Body | 1.0 | 400 |
| Small | 0.875 | 400 |

## Color Psychology
- Blue: Trust, calm, professional
- Green: Success, growth, nature
- Red: Urgency, error, passion
- Yellow: Warning, optimism
- Purple: Luxury, creativity
- Orange: Energy, enthusiasm
- Black: Sophistication, power
- White: Clean, minimal, pure
