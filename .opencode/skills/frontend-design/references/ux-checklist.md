# UX Evaluation Checklist

## Information Architecture
- [ ] Navigation is clear and consistent
- [ ] User knows where they are (breadcrumbs/indicators)
- [ ] Search is easily accessible if needed
- [ ] Important content is above the fold

## Forms & Inputs
- [ ] Labels are visible and descriptive
- [ ] Error messages are helpful and specific
- [ ] Required fields are clearly marked
- [ ] Inputs have appropriate type attributes
- [ ] Autofill is properly configured

## Feedback & Loading
- [ ] Actions have immediate visual feedback
- [ ] Loading states prevent double-submission
- [ ] Success/error messages are noticeable but not intrusive
- [ ] Long operations show progress

## Mobile & Touch
- [ ] Touch targets are minimum 44x44px
- [ ] Gestures don't conflict with browser gestures
- [ ] Content is readable without zooming
- [ ] Forms use appropriate input types (tel, email, etc.)

## Accessibility (WCAG 2.2)
- [ ] Color is not the only indicator
- [ ] Text has 4.5:1 contrast ratio minimum
- [ ] Page is usable with keyboard only
- [ ] Focus order is logical
- [ ] Alt text for all informative images
